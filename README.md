## 📚 Curriculum Milestones

1. **Initial Page Anatomy (`1 - Mi Primera Pagina`):** Basic `DOCTYPE`, `html`, `head`, and `body` scaffolding.
2. **Semantic Elements (`2 - Etiquetas`):** Core structural tags (`p`, `b`, `i`, `hr`, `br`).
3. **DOM Tree Nesting (`3 - Etiquetas anidadas`):** Proper tag containment rules and lexical document hierarchy.
4. **Content Hierarchy (`4 - Orden del Texto`):** Paragraph flows, lists, and typographical readability.
5. **Headings Taxonomy (`5 - Encabezados`):** Structured accessibility from `h1` through `h6`.
6. **Media Ingestion (`6 - Imagenes`):** Asset optimization, alt attributes, and responsive media tags.
7. **Biographical Architecture (`7 - Biografia`):** Multi-page interlinked website with navigation routing.
